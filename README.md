# Cubano Tires Mobile

Astro + TinaCMS source for the Cubano Tires Mobile website.

## Development

```bash
npm ci
npm run dev
```

## Validation and build

```bash
npm run build:full
```

The canonical source branch is `main`. The static GitHub Pages artifact is published from `gh-pages` and served at `https://staging.cubano.blissdrive.net/`.
